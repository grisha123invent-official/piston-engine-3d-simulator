## 🎯 Что это

Учебный симулятор для понимания физики двигателя внутреннего сгорания. Вся механика считается
честно — по реальной кинематике кривошипно-шатунного механизма, а не «на глазок»: положение
поршня в каждый момент вычисляется из угла коленвала, клапаны открываются по настоящим фазам
газораспределения, а давление и температура газа оцениваются по политропным процессам сжатия
и расширения.

Один файл `index.html`, никакой сборки и зависимостей в репозитории — открыл и работает.

## 🔄 Как работает цикл

За **два оборота коленвала (720°)** двигатель проходит четыре такта. Ниже — реальные кадры симулятора.

### 1️⃣ Впуск — 0…180°

<img src="docs/intake.png" alt="Такт впуска" width="100%">

Поршень идёт от ВМТ вниз, впускной клапан открыт (он открывается ещё за ~20° до ВМТ). Разрежение
над поршнем (~0,08 МПа) засасывает свежий заряд, форсунка впрыскивает распылённый бензин.
Смесь стехиометрическая — примерно **14,7 кг воздуха на 1 кг топлива**. Клапан закрывается с
запаздыванием ~50° после НМТ: поток по инерции продолжает наполнять цилиндр.

### 2️⃣ Сжатие — 180…360°

<img src="docs/compression.png" alt="Такт сжатия" width="100%">

Оба клапана закрыты, поршень сжимает смесь примерно в 10 раз. Газ при этом нагревается:
давление растёт до 1,5–2 МПа, температура — до 350–500 °C. За ~20° до ВМТ проскакивает искра
(**опережение зажигания**), чтобы максимум давления пришёлся точно на начало рабочего хода.

### 3️⃣ Рабочий ход — 360…540°

Фронт пламени пробегает камеру за тысячные доли секунды: **~2200–2500 °C и 4–6 МПа**. Расширяющиеся
газы толкают поршень вниз — это единственный такт, где двигатель совершает полезную работу.
Через шатун сила превращается во вращение коленвала, а маховик запасает энергию, чтобы «протащить»
вал через три остальных такта.

### 4️⃣ Выпуск — 540…720°

<img src="docs/exhaust.png" alt="Такт выпуска" width="100%">

Выпускной клапан открывается за ~50° до НМТ — остаточное давление само выбрасывает первую порцию
газов. Поршень выталкивает остальное (700–900 °C) в коллектор. У ВМТ наступает **перекрытие
клапанов**: оба приоткрыты, и уходящий поток помогает затянуть свежую смесь. Цикл повторяется.

## 🧪 Что под капотом (физика и модель)

**Кинематика.** Положение поршня относительно оси коленвала:

```
y(θ) = R·cos θ + √( L² − (R·sin θ)² )
```

где `R` — радиус кривошипа (половина хода поршня), `L` — длина шатуна, `θ` — угол поворота.
Именно из-за второго слагаемого движение поршня **не синусоидальное**: вниз от ВМТ он разгоняется
быстрее, чем поднимается к НМТ, — отсюда неравномерность нагрузок в реальном моторе.

**Фазы газораспределения** (углы цикла, 0° = ВМТ начала впуска):

| Событие | Угол | Комментарий |
|---|---|---|
| Открытие впускного | 700° (20° до ВМТ) | опережение для лучшего наполнения |
| Закрытие впускного | 230° (50° после НМТ) | инерционный «дозаряд» |
| Искра | 340° (20° до ВМТ) | опережение зажигания |
| Открытие выпускного | 490° (50° до НМТ) | свободный выпуск под давлением |
| Закрытие выпускного | 20° (после ВМТ) | перекрытие клапанов, продувка |

**Термодинамика.** Сжатие и расширение считаются как политропные процессы `p·Vⁿ = const`
(показатель ≈ 1,3), степень сжатия ≈ 10, сгорание моделируется плавным тепловыделением по
функции Вибе-образного вида. Цифры на приборах — порядок величин реального бензинового мотора,
а не точный термодинамический расчёт: цель — почувствовать, как связаны объём, давление и температура.

**Что ещё «течёт» в двигателе** (упомянуто в панели симулятора):
бензин под давлением 0,4 МПа (до 20 МПа при прямом впрыске), моторное масло на стенках цилиндра
и вкладышах, антифриз в рубашке охлаждения — в полезную работу превращается лишь ~30 % энергии топлива.

## 🎮 Управление

| Действие | Как |
|---|---|
| Вращать камеру | ЛКМ + движение |
| Приблизить / отдалить | Колесо мыши |
| Сдвинуть сцену | ПКМ + движение |
| Пауза / пуск | Кнопка **⏸** или **Пробел** |
| Шаг по циклу | Кнопки ±15° или **←** / **→** (с Shift — по 45°) |
| Перейти к такту | Кнопки «⏮ такт» / «такт ⏭», клик по шкале внизу |
| Скорость | Ползунок 5–600 об/мин |
| Разрез, подписи, газы | Чекбоксы в левой панели |

### Параметры URL

```
?deg=382     стартовый угол коленвала (0…719)
&rpm=120     скорость вращения
&pause=1     открыть на паузе
&cam=side    камера: side | iso | front | top
&ui=0        скрыть панели (чистая 3D-сцена для встраивания)
&still=1     отрисовать один кадр и остановиться (для скриншотов)
```

Пример: [`?deg=382&pause=1`](https://grisha123invent-official.github.io/piston-engine-3d-simulator/?deg=382&pause=1) — открыть сразу на вспышке рабочего хода.

## 🚀 Запуск локально

Сборка не нужна, но нужен HTTP-сервер (страница использует ES-модули, через `file://` браузер их заблокирует):

```bash
git clone https://github.com/grisha123invent-official/piston-engine-3d-simulator.git
```

```bash
cd piston-engine-3d-simulator && python3 -m http.server 8000
```

Затем открыть <http://localhost:8000>. Three.js подгружается с CDN — при первом запуске нужен интернет.

## 🛠 Стек

- [Three.js r185](https://threejs.org/) — WebGL-рендеринг, `OrbitControls`, `CSS2DRenderer` для подписей
- Чистые ES-модули через `importmap`, без бандлера и npm-зависимостей в репозитории
- HTML + CSS + JavaScript в одном файле `index.html`
